# sheetmusic-transformer
Transformer model trained on public MusicXML files. 
Playing around with PyTorch and a public MusicXML database to see how effective it could be to train AI models on musical symbols/notes rather than sounds and audio files. Basically, attempting to do natural language processing with the language of music.



## Dataset & Attribution

This project uses the [PDMX dataset](https://github.com/pnlong/PDMX) for symbolic music data. Please refer to the original PDMX repository for dataset access, licensing, and citation requirements.

**Publications:**
- Long et al., [PDMX: A Large-Scale Public Domain MusicXML Dataset for Symbolic Music Processing](https://doi.org/10.1109/ICASSP49660.2025.10890217).
- Xu et al., [Generating Symbolic Music from Natural Language Prompts using an LLM-Enhanced Dataset](https://arxiv.org/abs/2410.02084).
